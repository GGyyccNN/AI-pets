# 后续工作路线图

推荐定位：**能跨 coding harness 反映可信工作状态的桌宠**。继续复用 Electron 桌宠基线，以 WavePet 为状态层；DSH 是下一条优先适配路径。

以下均为工作计划和验收目标，不是已实现功能。方向依据见 [2026-10-13 调研](research/ecosystem-2026-10-13.md)。

## 现状

- [x] 迁入原 Electron 桌宠及 JavaScript WavePet/Codex 适配。
- [x] 迁入独立 Python plugin/skill、MIT 通知与 marketplace。
- [x] 保留来源提交与原有主题/素材许可。
- [x] 增加无 GUI 的事件回放和 JS/Python/文件桥 smoke。
- [ ] DSH 接入、统一生命周期、多会话体验层、原创状态素材：待开发。
- [ ] 桌面系统实机验收、公开发布与真实用户验证：待进行。

## P0：先建立可验证的状态语义

1. 编写 `pet.activity.v1` 协议提案：source/session/turn/attempt/event ID、时间、生命周期、工具活动、体验信号、触发原因、连接状态和能力声明。
2. 按会话持有状态；去重、乱序、重试、会话退出有明确定义。缺少 thinking/token 等信号时声明 unavailable，不能伪造零值表示“确知为零”。
3. 审批/需输入、明确 fatal failure 和连接未知优先可见；普通工具失败与可恢复调试不等于整任务失败。
4. 为现有 JS 与 Python 引擎建立共享事件 fixture；先对行为差异分类，再决定哪些统一，哪些属于桌面特有视觉策略。
5. 保留 Codex hooks primary / JSONL fallback，核查是否重复累计、旧 completion 覆盖新 turn、静默计时是否真正周期更新。

验收：确定性回放包含两会话交错、重复事件、乱序、工具并行/重试、审批等待、取消、失败后恢复、终端断连和日志缺失；关键生命周期不能被动画最小保持时间延迟或覆盖。单元场景中完成/失败/取消/未知互不混淆。

## P1：DSH 只读状态桥

1. 选定一个实际可安装的 DSH release，记录 host/API 版本；源码 alpha 只用作接口研究参考。
2. 在 Cordis host 插件监听 agent/session/工具/审批和 stream 事件，转成 P0 协议；通过有超时、限流和失败隔离的本地通道送入桌宠。
3. 仅观察审批，保证 waterfall `next()` 和原执行不被阻塞；不复制模型 Key，也不让宠物成为模型代理。
4. 先通过无 Key 的 fixture/host 测试，再用真实 DSH 验证读文件、编辑、测试成功/失败、等待用户和取消。明确是否支持官方 Desktop、Web 与具体社区壳。
5. 断连显示 unknown，恢复后重建当前快照；重播历史不重复庆祝。

验收目标：本机正常负载下关键状态从收到事件到显示 p95 ≤ 1 秒；审批等待漏报、取消误报成功、桌宠故障阻塞 agent 在验收任务中为 0。记录测试任务数与条件，不将小样本“零失败”当成整体可靠性保证。

## P2：多状态和多会话体验

1. 保留 5 种等待体验，新增明确的生命周期覆盖；不要把所有活动/情绪/动画揉成几十个互斥状态。
2. 工具 read/edit/test 的短期表现覆盖与长时工作压力独立；长时动画平滑，关键审批/失败立即切换。
3. HUD 展示当前会话与“需要你”的其他会话；点击定位已有终端，切换关注对象有可见说明。
4. 先做一套有明确可分发权利的主题；兼容现有 Codex/Petdex sprite，未支持的动作使用 badge/overlay 和明确 fallback。
5. 默认安静工作、完成轻提示、审批强提示，尊重 DND 和减少动画选项。

验收：用户可区分工作、等自己、调试中、已完成、断连；对相同任务录屏比较误报完成、关键等待漏报、每分钟无意义状态切换、返回终端查看次数以及用户干扰评分。

## P3：验证研究收益并决定分发形态

- 先用 5–10 位多会话用户、经授权的真实时间事件和独立人工标注评估规则版。
- 按 session/trajectory 分组切分，防止同任务前缀流入训练与测试两侧；对照基础生命周期宠物与 WavePet 增强版。
- 只有在状态识别和实际体验指标都有收益时引入 TokenWave 学习校准；否则保留轻量规则。
- 优先通过 DSH 插件/适配器与现有图库分发；是否把 WavePet 输出给 OpenPets/其他 renderer，取决于差异化验证。

## 暂缓项

完整 AI 伴侣语音链路、长期人格/记忆、完整素材商城、复杂养成、精确剩余时间预测、一次支持全部 harness、同时重写桌面壳。它们不阻止当前状态桌宠闭环，且会分散验证工作。
